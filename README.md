# Calendrier B.O.C.

Calendrier autonome : événements, flyers et visuels inclus.

## Publication
Dans Settings → Pages, choisir Deploy from a branch, puis main et / (root), puis Save.

## Mise à jour
Modifier events.json pour ajouter ou corriger un événement. Ajouter les flyers dans assets/ et utiliser un chemin relatif (assets/nom.jpg).

La vérification automatique du NAS par ChatGPT ne fait pas partie de cette copie.
